# RipAdbaisor

Aplicación desarrollada en Java para gestionar un sistema de valoración de elementos mediante ranking.

## Características

- Añadir elementos
- Mostrar elementos
- Editar puntuaciones
- Eliminar elementos
- Validación de datos
- Uso de ArrayList
- Interfaz gráfica con JOptionPane

## Tecnologías utilizadas

- Java
- Swing
- Git y GitHub

## Estructura del proyecto

- modelo
- servicios
- ui
